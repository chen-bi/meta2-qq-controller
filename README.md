让 QQ 机器人（AstrBot）在聊天里控制元力系列设备：**振动、伸缩、旋转三个通道分开调**。
设备用电脑蓝牙直连，不经过手机 App。

## 功能

- 三个通道独立控制（0-100 / 0-99），可以给三个不同的值
- 模型自己判断：聊天气氛上来就推，缓下来就退，不用你报数字
- 18 种自动节奏预设（rush / edge / chaos / torture …）
- 安全阀：白名单、档位上限、最小调整间隔、防抖台阶

## 你需要什么

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（只在 Windows 验证过） |
| Python | 3.10 以上 |
| 蓝牙 | 笔记本自带即可，台式机需外接适配器 |
| 机器人 | 已经跑起来的 AstrBot（能正常收发 QQ 消息） |
| 设备 | 蓝牙名带 `META` 的元力系列（TF-META2 / DK-META2 实测可用） |

> ⚠️ 设备同一次只能连一个主。用之前**手机上把 App 的连接断开**，否则电脑连不上。

## 快速开始

### 1. 装控制端

右键 `安装.ps1` → **使用 PowerShell 运行**。
它会复制文件到 `%USERPROFILE%\meta2-controller`，建 venv，装 `bleak`。

### 2. 装插件

把 `插件\astrbot_plugin_meta2\` 复制到 AstrBot 的 `data\plugins\` 下，然后重载插件。

### 3. 填你自己的 QQ 号

后台 → 插件 → 元力2代远程控制 → `allowed_qq` 填自己的号。其余留空即可。

### 4. 人设

包里不带人设。`人设\人设模板.md` 是骨架，照着填，后台新建人格粘进去，绑到会话上。

人格是**按会话**生效的：私聊一个会话、每个群一个会话。所以只有一个 QQ 号也能用 ——
建一个只有你和机器人的群，给那个群单独绑「设备版」人格就行。

### 5. 开始用

在绑好人设的会话里发 `开始`，第一次约 10-20 秒扫蓝牙。之后：

| 你说 | 会发生什么 |
|---|---|
| 继续 / 快点 / 别停 | 她往上推 |
| 慢点 / 受不了 | 她往下退 |
| 停 | 归零断开 |

手动兜底：`震动 60` / `伸缩 80` / `旋转 50 反` / `预设 rush` / `状态`

## 只用一个 QQ 号

插件只认「哪个会话 + 谁的 QQ 号」，不要求开第二个号。三种玩法：

| 方案 | 做法 |
|---|---|
| A 最省事 | 把模板里【设备这条线】那段加进你原人设，靠 `开始` / `停` 开关 |
| B 推荐 | 建个只有你和机器人的群，群里绑「设备版」人格，日常私聊不受影响 |
| C | 两个号各配一套（作者用的这个，需要两个 NapCat 实例） |

## 常见问题

| 现象 | 处理 |
|---|---|
| 说「开始」后等很久 | 正常，在扫蓝牙。设备要开机、手机要断开 |
| 回「设备服务没在跑」 | 重跑 `安装.ps1`，或检查 Python 路径 |
| 扫不到设备 | 手机还连着 / 设备休眠 / 距离太远（1 米内） |
| 连上但不动 | 型号不同，命令字可能不一样，见下 |
| 她只说话不动手 | 人设里没写设备段，或 `llm_enabled` 被关了 |
| 动一下就停 | 蓝牙掉线，重发 `开始` |

### 型号不同

包是按 `TF-META2` / `DK-META2` 写的。连上但不执行的话，改 `meta2.py` 里的
`CMD_VIBRATE` / `CMD_OSCILLATE` / `CMD_ROTATE` 命令字；完全不同的品牌需要按那家协议重写。

## 安全

- 设备有物理开关，任何情况可以直接关掉
- 脚本结束自动归零；异常退出后重发 `开始` 或断开蓝牙
- 纯本地工具，不联网（只有本机 127.0.0.1 通信）
- `allowed_qq` 是唯一能把设备交给别人的开关，别填错
